# Документация по коду

Карта прошивок комнатного монитора CO2: что делает каждый файл, как данные ходят между STM32 и ESP32, куда править пороги и команды.

Определение 1: прошивка (firmware, программный образ микроконтроллера) — это скомпилированная программа, которую записывают во flash чипа. У устройства две независимые прошивки: STM32 (датчик, часы, звук) и ESP32 (экран, Wi‑Fi, веб).

Определение 2: STM32 (STMicroelectronics 32-bit) — микроконтроллер «железа»: опрашивает SCD41, читает DS3231, пищит зуммером и шлёт JSON по UART. Без ESP32 измерения и звук продолжают работать.

Определение 3: ESP32 (Espressif 32-bit Wi‑Fi MCU) — второй чип: рисует LCD, поднимает веб, синхронизирует время по NTP и проксирует кнопки HTML в UART-команды на STM32.

Определение 4: модуль (module, логический кусок исходников) — пара `.h` + `.c`/`.cpp` с одной ответственностью (датчик, зуммер, веб). Ниже — оглавление модулей, не даташит чипа.

## Где лежит прикладной код

```
stm32_cube/co2_stm32/Core/   ← свой код STM32 (не трогать Drivers/)
esp32/src/                   ← прошивка ESP32
esp32/include/               ← заголовки ESP32
```

Файлы CubeMX (`i2c.c`, `tim.c`, `gpio.c`, большая часть `main.c`) перезаписываются Generate. Свой алгоритм — только в зонах `USER CODE` и в отдельных файлах `scd41.c`, `alert_fsm.c` и т.д.
